HUSSIEN PORTFOLIO — QUICK START
================================

WHAT'S INCLUDED
- index.html: the complete responsive portfolio website
- images/: the 12 original uploaded images, copied into the site folder
- The portfolio shows 8 curated project cards and avoids listing the overview collage and gig thumbnail as separate client projects.
- Clicking a project opens a larger preview in an on-page lightbox. YOUNIQÉ and 5Senses each include two related images in the lightbox.

HOW TO PREVIEW ON YOUR COMPUTER
1. Extract hussien-portfolio-site.zip to a folder.
2. Open the extracted folder.
3. Double-click index.html. It should open in your web browser.
4. Click Portfolio filters and project cards to test the page.

BEFORE PUBLISHING
1. Open index.html in Notepad (right-click index.html > Open with > Notepad).
2. Find YOUR-EMAIL@example.com and replace it with your preferred business email.
3. Save the file. Do not change image file names or move the images folder.
4. Upload index.html and the entire images folder to your hosting provider. Keep the folder structure intact.

IMPORTANT
- This is a static website; no coding knowledge is required to preview it.
- The contact button uses an email link. Add your real email before publishing.
- The portfolio text describes the visual work only; no unsupported sales/conversion results are claimed.
- If you use a website builder, the HTML file may not be directly importable. This package is intended for regular static web hosting or for a developer to upload.
